The four conventions

FamilyThe hidden conventionTasks
IdentifiersKIND in capitals (first three letters), a hyphen, the number padded to five digitsorder_id, invoice_id, customer_id, shipment_id, refund_id, ticket_id
Prices₹, thousands separators, two decimals; refunds and discounts get a leading minusformat_price, format_refund, format_total, format_fee, format_discount, format_balance
DatesDD-Mon-YYYY, such as 05-Mar-2026format_date, format_birthday, format_expiry, format_deadline, format_start, format_range

Hidden tests and the two reference answers

The hidden tests (not shown to the model until one fails)

assert format_range(2026, 3, 5, 2026, 3, 9) == '05-Mar-2026 to 09-Mar-2026'
assert format_range(2026, 12, 30, 2027, 1, 2) == '30-Dec-2026 to 02-Jan-2027'
assert format_range(2030, 6, 1, 2030, 6, 1) == '01-Jun-2030 to 01-Jun-2030'

def format_range(y1, m1, d1, y2, m2, d2):

The reference answer, which passes

def format_range(y1, m1, d1, y2, m2, d2):
    months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']
    f = lambda y, m, d: f'{d:02d}-{months[m - 1]}-{y}'
    return f(y1, m1, d1) + ' to ' + f(y2, m2, d2)

def parse_age(s):
    try:
        n = int(s)
    except ValueError:
        raise ValueError(f'invalid age: {s}') from None
    if not 0 <= n <= 150:
        raise ValueError(f'invalid age: {s}')
    return n
