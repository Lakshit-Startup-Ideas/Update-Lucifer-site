Follow one lesson from failure to success

A single convention, traced through the whole experiment.

  1. 1 · An experience taskThe model is asked for format_date: “format_date(year, month, day) writes a calendar date as text.” A plain answer writes an ISO date like 2026-03-05.
  2. 2 · The referee says noThis is the real message from the sandbox, produced by running the plain answer: this check failed: assert format_date(2026, 3, 5) == '05-Mar-2026' (AssertionError: )
  3. 3 · A lesson is writtenLucifer and Wrong notes store the lesson (see the full text). No memory stores nothing.
  4. 4 · A similar task arrives laterThe model is asked for format_deadline: “format_deadline(year, month, day) writes a deadline date as text.” Lucifer's retrieval puts the three most relevant lessons in its prompt (every Lucifer similar attempt in this run was shown at least one lesson). The test can say no

A measurement is only worth trusting if it can come out negative. Before any real run, the lab was checked on simulated agents with a known truth, so we could see whether the gates tell them apart. These are automated tests in tests/test_controls.py:

An agent that cannot learn

Must almost never be reported as improving. (test_an_agent_that_cannot_learn_is_almost_never_reported_as_improving)

An agent that learns

Must be detected once the task set is large enough. (test_with_about_four_times_the_tasks_a_real_effect_is_detected_and_a_null_one_is_not)

An agent hurt by memory

Must be reported as hurt. (test_an_agent_hurt_by_memory_is_reported_as_hurt)

This is also why the result is a first look. The same tests show that a set with only 12 primary tasks misses a real effect (test_a_set_with_only_12_primary_tasks_misses_a_real_effect_so_it_must_not_be_trusted). This run had 18. See the power table.

Run it yourself

Run the lab and its tests

git clone https://github.com/Lakshit-Startup-Ideas/Lucifer-BenchMarks
cd Lucifer-BenchMarks
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/pytest

125 tests, about four minutes.

Repeat the experiment on GitHub

# Actions → Experiment → Run workflow
model     qwen2.5-coder:14b
taskset   convention
seeds     5
publish   true

One job per seed, then a merge and the three gates in the job summary. No GPU and no local model needed.

The files behind this site: results/published/qwen14b-convention (commit 1a88d19), the workflow run 43163827087, the task set in src/lucifer/tasks.py, and the plan that fixed the gates in advance, docs/EXPERIMENT-PLAN.md.
